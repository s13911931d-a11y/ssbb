# تغییرات SSB: مدیریت فضاها و نمایش تمام‌صفحه

## تغییرات
- پنل مدیریت فهرست گروه‌ها و کانال‌ها را با سازنده، تعداد اعضا و وضعیت نمایش می‌دهد.
- مدیر می‌تواند گروه/کانال را مسدود و دوباره فعال کند؛ کانال رسمی SSB محافظت شده است.
- دسترسی به فضای مسدودشده در صفحه و رویدادهای Socket.IO رد می‌شود.
- تماس و پخش زنده با نمای تمام‌صفحه درون برنامه باز می‌شوند تا محتوا به پایین صفحه نرود.
- در مرورگرهای سازگار، هنگام اقدام کاربر درخواست Fullscreen API ارسال می‌شود؛ اگر مرورگر اجازه ندهد، نمای تمام‌صفحه CSS استفاده می‌شود.
- دکمه «کوچک‌کردن» برای برگشت به صفحه عادی اضافه شده است.

## اجرا
1. Node.js 20 یا جدیدتر نصب باشد.
2. در این پوشه ترمینال باز کنید و اجرا کنید:
   ```cmd
   npm install
   npm start
   ```
3. به `http://localhost:3000` بروید.

## یادداشت
- برای تماس و پخش زنده واقعی بین دستگاه‌ها HTTPS و در بسیاری از شبکه‌ها TURN لازم است.
- مرورگرها اجازه نمی‌دهند صفحه بدون اقدام کاربر همیشه به fullscreen واقعی برود؛ در این موارد SSB از نمای تمام‌صفحه داخل صفحه استفاده می‌کند.
- برای استفاده عمومی، متغیر `SESSION_SECRET` را در محیط استقرار به یک مقدار تصادفی و امن تغییر دهید.
