# SSB Node.js — نسخه آزمایشی بعدی

## اجرا در ویندوز
1. Node.js نسخه LTS (ترجیحاً 20 یا جدیدتر) را از https://nodejs.org نصب کنید.
2. این پوشه را استخراج کنید و در پوشه `SSB_NodeJS_edit` از نوار آدرس File Explorer عبارت `cmd` را وارد کنید.
3. اجرا کنید:

```cmd
npm install
npm start
```

4. مرورگر: http://localhost:3000

ورود مدیر پیش‌فرض: `admin` / `ChangeMe-123!` — بلافاصله رمز را عوض کنید؛ این نمونه فعلاً صفحه تغییر رمز ندارد، پس قبل از استفاده آنلاین باید تنظیم شود.

## قابلیت‌ها و وضعیت
- حساب کاربری و نشست ورود، پیام متنی، فایل و ضبط پیام صوتی.
- گفت‌وگوی مستقیم با انتخاب مخاطب از فهرست؛ پیام‌های DM فقط در صفحه همان گفت‌وگو نشان داده می‌شوند.
- کانال رسمی `SSB` به‌صورت پیش‌فرض ساخته می‌شود؛ فقط مدیر اجازه ارسال در آن دارد.
- پنل مدیریت همه پیام‌های ذخیره‌شده را نشان می‌دهد، از جمله DM؛ این رفتار باید به کاربران اعلام شود.
- ساخت گروه/کانال، عضویت در گروه، تغییر نام/عکس و تنظیم اعضای گروه.
- تماس مستقیم صوتی/تصویری آزمایشی با WebRTC و پخش زنده صوت/تصویر آزمایشی با چت.
- ایموجی در پیام متنی.

## محدودیت‌های مهم
این پروژه هنوز محصول آماده انتشار نیست. تماس گروهی کامل با حداکثر ۱۰ نفر در این بسته به‌طور کامل پیاده‌سازی و آزمایش نشده است؛ تماس مستقیم یک‌به‌یک و نمونه پخش زنده میزبان-بیننده در نظر گرفته شده‌اند. پخش زنده در شبکه‌های مختلف به HTTPS و معمولاً سرور TURN نیاز دارد. برای پیام‌رسانی هم‌زمان و چندسروری، ذخیره‌سازی امن و کنترل دسترسی تولیدی، تست امنیت و پایگاه‌داده واقعی لازم است. از این نسخه روی اینترنت عمومی استفاده نکنید.

## داده‌ها
کاربران و پیام‌ها در `data.json` و فایل‌ها در `uploads/` نگهداری می‌شوند. فایل `data.json` حاوی هش رمز عبور است و باید محافظت شود. کلید `SESSION_SECRET` را قبل از استفاده محلی جدی تنظیم کنید.
