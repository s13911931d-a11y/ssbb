SSB — اصلاح آزمایشی تماس تصویری

این نسخه مشکل رایج گم‌شدن ICE candidateها را رفع می‌کند: مرورگر گیرنده ممکن است قبل از زدن «پاسخ» کاندیداهای شبکه را دریافت کند، اما نسخه قبلی آن‌ها را دور می‌ریخت. اکنون کاندیداها تا آماده‌شدن remoteDescription نگه داشته و سپس اضافه می‌شوند. وضعیت اتصال و خطاهای سیگنال‌دهی نیز نمایش داده می‌شوند.

اجرا:
1) Node.js 20 یا جدیدتر نصب باشد.
2) در این پوشه CMD باز کنید.
3) npm install
4) npm start
5) در همان کامپیوتر http://localhost:3000 را باز کنید.

آزمایش دو کاربر روی یک کامپیوتر:
- از دو پروفایل مرورگر جداگانه (مثلاً Chrome و Edge، یا پنجره پروفایل جدا) استفاده کنید؛ هر پروفایل باید با حساب کاربری متفاوت وارد شود.
- هر دو صفحه را روی localhost باز کنید و مجوز میکروفون/دوربین بدهید.
- در صفحه اول نام کاربری دقیق حساب دوم را وارد و تماس را آغاز کنید؛ در صفحه دوم «پاسخ به تماس» را بزنید.
- اگر دو تب از یک پروفایل و یک نشست یکسان استفاده کنند، هر دو در واقع یک کاربر هستند و تست تماس بین دو حساب محسوب نمی‌شود.

محدودیت‌ها:
- این یک اصلاح کد است، نه تضمین رفع همه مشکلات. تماس باید روی دو نشست حساب جداگانه آزمایش شود.
- STUN عمومی تنظیم شده است؛ برخی شبکه‌ها برای برقراری اتصال به TURN نیاز دارند.
- localhost برای آزمایش دوربین/میکروفون secure context محسوب می‌شود. برای دسترسی از دستگاه‌های دیگر، HTTPS و معمولاً TURN لازم است.
